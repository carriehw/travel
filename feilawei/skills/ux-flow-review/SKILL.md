# Skill: UX Flow Review

## Goal
確保玩法簡單、清晰、唔重複、唔令人覺得填問卷。

## Review questions
- 用戶知唔知而家要做咩？
- 每頁是否只有一個主要行動？
- 問題是否真的影響 recommendation？
- 有冇可合併問題？
- 返回後答案會唔會保留？
- 已去過 / 不想再出現是否清楚不同？
- 同樣條件重玩時是否有 anti-repeat？
- reveal 前是否有期待感？
- result 是否清楚解釋「點解適合你」？

## Output
- finding
- severity
- recommended change
- whether visual master is affected
