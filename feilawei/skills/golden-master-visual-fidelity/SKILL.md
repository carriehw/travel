# Skill: Golden Master Visual Fidelity

## Use when
Implementing or reviewing any screen of 飛啦喂！.

## Inputs
- approved Golden Master
- target viewport
- asset manifest
- current live screenshot

## Process
1. Lock target viewport.
2. Identify immutable artwork.
3. Separate artwork from real HTML text.
4. Measure positions relative to artboard.
5. Implement without redesign.
6. Capture live screenshot.
7. Create 50% overlay comparison.
8. Log all visible mismatches.
9. Fix highest-impact mismatch first.
10. Repeat until pass.

## Hard rules
- Never redraw mascot.
- Never substitute generic iconography.
- Never stretch artwork.
- Never declare pass based only on successful deployment.
